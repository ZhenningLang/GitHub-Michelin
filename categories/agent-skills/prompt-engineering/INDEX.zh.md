## 什么该放这里

主业是**提示词工程本身**的 skill 与仓库——为 LLM 及其他 AI 工具生成、改进、收集或教学提示词。领域专用的提示词包（写作、设计、安全）留在各自任务叶子；本叶子只收工具无关的提示词工作。
