# design-to-code

> [design](../INDEX.zh.md) 的叶子。把**一个具体的设计参照对象**——某个具名站点的外观、Stitch 画出的界面、一个现成网站——变成落地 UI 代码的 skill。设计方向是被给定的，不是现场发明的。
> ← 上层 [design](../INDEX.zh.md) · 根 [路由](../../../../INDEX.zh.md) · English: [INDEX.md](INDEX.md)

## 本叶子的合集

| 合集 | 何时用 | 健康度 | 页面 |
| --- | --- | --- | --- |
| **Stitch Skills** | 一套遵循 Agent Skills 开放标准的技能库，驱动 Google 的 Stitch MCP server 生成 UI 屏幕、在代码与设计间双向转换、抽取 DESIGN.md，并导出 React/React Native/shadcn 组件。 | B（4/5） | [→](stitch-skills.zh.md) |
| **Awesome DESIGN.md** | 当要把某个知名站点的样子变成一份可丢进项目的 DESIGN.md 时用；要自己的品牌或品味 skill、或指望 harness 自动加载时不要用。 | B（4/5） | [→](awesome-design-md.zh.md) |
| **ai-website-cloner-template** | 面向获授权网站重建的 AI coding agent template：截图、设计 token、资产、组件规格、并行 builder 和视觉 QA。 | B（4/5） | [→](ai-website-cloner-template.zh.md) |

## 什么该放这里

职责是**把已有或具名的设计搬进可用 UI** 的 skill：设计工具往返、从真实站点抄来的参照 `DESIGN.md`、整站重建。没有给定参照对象、只引导 agent 自写 UI 品味的看 [ui-taste](../ui-taste/INDEX.zh.md)；交付物本身是独立视觉产物（图、原型、幻灯片）的看 [visual-artifacts](../visual-artifacts/INDEX.zh.md)。
