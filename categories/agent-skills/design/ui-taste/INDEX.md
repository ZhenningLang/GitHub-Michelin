## What belongs here

Skill packs that give the agent **design judgment for the UI it writes** — taste, anti-slop rules, polish checklists, review/critique protocols. The output is agent-authored interface code steered by the skill, not a copy of a named design (see [design-to-code](../design-to-code/INDEX.md)) and not a standalone visual artifact (see [visual-artifacts](../visual-artifacts/INDEX.md)).
