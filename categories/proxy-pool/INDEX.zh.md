# proxy-pool

> 分类节点。面向网络爬虫的自托管轮换代理 IP 池。
> ← 返回[分类路由](../../INDEX.zh.md) · English: [INDEX.md](INDEX.md)

## 本分类项目

| 项目 | 何时用 | 健康度 | 页面 |
| --- | --- | --- | --- |
| **proxy_pool** | 当业余或研究用的爬虫老被封 IP、你想自托管一个免费代理池，让它爬取、校验并通过 Redis 支撑的 HTTP API 吐出可用 IP 时用它——但免费代理又慢又短命且不可信，绝不要让敏感流量经过。 | C（5/6） | [→](proxy-pool.zh.md) |
| **ProxyBroker** | 当低风险原型需要临时找一批免费代理、检查匿名度并经一个本地轮换端点提供时用它——但它自 2019-03 起休眠，据报在新版 Python 上不钉死环境普遍跑不起来。 | D（4/6） | [→](proxybroker.zh.md) |
| **Scylla** | 当你想用一条 `docker run` 起一个常驻免费代理服务、通过 JSON API 按 HTTPS 支持、匿名度和国家筛选并带看板时用它——但内置正向代理不支持 HTTPS，发版自 2022 年起停滞。 | D（4/6） | [→](scylla.zh.md) |
| **haipproxy** | 当多台机器上的大量爬虫需要一个分布式、高可用的免费代理池，并想把收割、校验、调度在 Scrapy + Redis 上解耦时用它——但它自 2019-07 起休眠，跑的是 Python 2/3 过渡期代码，且是最重的代理池。 | D（4/6） | [→](haipproxy.zh.md) |

## 对比矩阵

| 选项 | 是否收录 | 健康度 | 一句话取舍 |
| --- | --- | --- | --- |
| [proxy_pool](proxy-pool.zh.md) | ✅ | C（5/6） | 换来免费的 IP 轮换、一个极简 HTTP API 和一个仍有提交的长寿代码库；代价是要运维 Redis 和调度进程、池子大小不可预测，而且除了换 IP 不做任何反爬规避。 |
| [ProxyBroker](proxybroker.zh.md) | ✅ | D（4/6） | 换来一个 pip 即装、无需另跑数据库的 asyncio CLI，发现、校验、服务三合一；代价是代码已冻结、缺代理鉴权和在线率追踪，以及公开代理一贯的不可靠。 |
| [Scylla](scylla.zh.md) | ✅ | D（4/6） | 换来一个打过分、可查询、多个任务共用的代理池，一个容器就能起；代价是 HTTPS 只能拿 API 列表自己连、单维护者仓库正滑向休眠，以及免费代理的不稳。 |
| [haipproxy](haipproxy.zh.md) | ✅ | D（4/6） | 换来代理收割的横向扩展和节点容错；代价是要运维 Redis（可能还有 Splash）、给冻结代码做兼容修补，而池子里终究只是不稳的免费代理。 |
| paid residential proxies | 未收录 | — | 各页对比里点到的付费代理服务；它们不是仓库，因此不在收录范围内（scylla 已在上方单独列出）。 |

## 什么该放这里

面向网络爬虫的自托管**轮换代理 IP 池**。不含爬虫框架本身，不含 Web/浏览器自动化（见 `web-automation`）。
