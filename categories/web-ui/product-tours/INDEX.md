| Project | Use when | Health | Page |
| --- | --- | --- | --- |
| **Driver.js** | A lightweight, dependency-free JavaScript/TypeScript library that draws an overlay and spotlight to guide user focus across a web page — product tours, feature highlights, and step-by-step onboarding, with no framework and no runtime deps. | B (5/6) | [→](driver-js.md) |
| **Intro.js** | Use it when a plain HTML or vanilla-JS site needs a step-by-step spotlight walkthrough configured through data attributes, with built-in translations and themes — but it is AGPL-3.0, commercial products need a paid license, and one contributor does all current work. | B (5/6) | [→](intro-js.md) |
| **react-joyride** | Use it when a React or Next.js app needs a first-run tour whose steps follow components that mount late or move, rendered as React portals — but it is React-only, effectively one maintainer, and v3 silently breaks unmigrated v2 code. | B (6/6) | [→](react-joyride.md) |
| **Reactour** | Use it when a React app needs a step-by-step tour or a one-off element highlight driven by React context and a useTour hook, under MIT — but releases are slow (last @reactour/tour 3.8.0 in 2025-05) and one person maintains it. | B (5/6) | [→](reactour.md) |
| **Shepherd.js** | Use it when one tour engine must run across React, Angular, and plain-HTML surfaces and advance only after real user clicks — but since v14 (2024-09) revenue-generating companies, even for internal dashboards, need a paid commercial license. | B (4/6) | [→](shepherd-js.md) |
