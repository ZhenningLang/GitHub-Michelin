## Projects in this category

| Project | Use when | Health | Page |
| --- | --- | --- | --- |
| **Ant Design** | Use it when a React back-office app is mostly sortable, filterable tables and complex forms and you want a free, complete, consistently designed component set without a designer — but it is React-only, and v6 requires React 18 or newer. | A (6/6) | [→](ant-design.md) |
| **Chakra UI** | Use it when a small team builds a branded React or Next.js SaaS and wants accessible components styled through props from one theme — but styles still render at runtime via Emotion, and it lacks Ant-level data grids and form engines. | A (6/6) | [→](chakra-ui.md) |
| **Material UI (MUI)** | Use it when a React team without a designer must ship many CRUD screens fast and accepts Google's Material Design look — but a distinctive brand means overriding component after component, and Tailwind-first stacks end up maintaining two styling systems. | A (6/6) | [→](material-ui.md) |
| **Radix UI Primitives** | Use it when building your own React design system and you need dropdowns, dialogs, and tooltips with keyboard, focus, and ARIA behavior done but zero styling — but it has no combobox or date picker, and upkeep hinges on one WorkOS maintainer. | A (6/6) | [→](radix-ui.md) |
| **shadcn/ui** | Use it when you start a React product on Tailwind and want polished, accessible components copied into your repo as source you edit freely — but you own and maintain every copied file, and the project leans on its creator's judgment. | A (6/6) | [→](shadcn-ui.md) |
| **TanStack Ranger** | A slider needs two thumbs, an irregular step array or a log-scale fader and the markup must stay entirely yours — a headless value engine does drag tracking, snapping, ticks and percentages and renders nothing; only the React adapter ships, and the API is still 0.x. | C (5/6) | [→](tanstack-ranger.md) |
| **TanStack Select** | You need a searchable, multi-value dropdown with your own markup and hope for a TanStack-style headless engine — watch-list only: `main` is an empty scaffold with a rewrite RFC, nothing on npm; the only shipped code is the unmaintained, ARIA-less React-16 hook `use-select`. | C (4/6) | [→](tanstack-select.md) |
| **TanStack Table** | Your table must sort, filter, paginate, group and select rows, but the exact `<table>` DOM and styles must stay yours — a headless engine computes the state and row models while you write the markup. | A (6/6) | [→](tanstack-table.md) |
| **TanStack Time** | Your product calendar needs recurrence, drag-resize and double-booking checks with the DOM staying yours — a headless, Temporal-native core computes the day grid, occurrences and conflicts. Watch-list bet: unreleased pre-alpha, nothing on npm yet. | D (4/6) | [→](tanstack-time.md) |
