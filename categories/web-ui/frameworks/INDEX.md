## What belongs here

Front-end frameworks and meta-frameworks for building web applications — including content- and documentation-site frameworks (Astro, Docusaurus, Nextra), which are meta-frameworks over React whose application is a site. Not component libraries or design systems (see `web-ui/component-libraries`), not browser automation (see `web-automation`), and not typesetting or document compilers that emit PDF rather than a running site (see `typesetting`).
