# site-frameworks

> 分类节点。内容站与文档站框架——产出物是一个由 Markdown/MDX 生成、以静态为主的站点。
> ← 返回[frameworks](../INDEX.zh.md) · root: [分类路由](../../../../INDEX.zh.md) · English: [INDEX.md](INDEX.md)

## 本分类项目

| 项目 | 何时用 | 健康度 | 页面 |
| --- | --- | --- | --- |
| **Astro** | 当站点是内容集合、只需少数交互组件时用它——但交付物是带版本的文档站、或站点本质是全栈应用时不要用。 | A（5/6） | [→](astro.zh.md) |
| **Docusaurus** | 当需要第一天就有带版本、可搜索、支持 i18n 的文档站时用它——但站点是通用内容站、或你宁愿自己组装文档那套家具时不要用。 | B（6/6） | [→](docusaurus.zh.md) |
| **Nextra** | 当文档必须活在既有 Next.js 应用里、一层薄 MDX 就够了时用它——但你需要版本化文档、或需要背后有较大维护团队的项目时不要用。 | B（6/6） | [→](nextra.zh.md) |

## 什么该放这里

应用本身就是一个站点的框架：内容集合、带版本／搜索／i18n 的文档、MDX 主题（Astro、Docusaurus、Nextra）。通用 Web 应用归 `app-frameworks`；产出 PDF 而非可运行站点的排版与文档编译器归 `typesetting`。
