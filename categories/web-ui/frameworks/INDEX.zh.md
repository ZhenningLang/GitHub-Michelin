# frameworks

> 分类节点。用于构建 Web 应用的前端框架与元框架。
> ← 返回[web-ui](../INDEX.zh.md) · root: [分类路由](../../../INDEX.zh.md) · English: [INDEX.md](INDEX.md)

## 子分类

| 分类 | 何时用 | 路由 |
|---|---|---|
| **view-frameworks** | 组件与视图层框架——在浏览器里渲染组件、管理响应式的那层运行时。 | [→](view-frameworks/INDEX.zh.md) |
| **app-frameworks** | 全栈应用元框架与路由——在视图框架之上补齐路由、数据加载、SSR 与服务端代码。 | [→](app-frameworks/INDEX.zh.md) |
| **site-frameworks** | 内容站与文档站框架——产出物是一个由 Markdown/MDX 生成、以静态为主的站点。 | [→](site-frameworks/INDEX.zh.md) |

## 什么该放这里

用于构建 Web 应用的前端框架与元框架，按你在选什么来分：视图层（`view-frameworks`）、叠在其上的应用框架或路由（`app-frameworks`）、产出物是内容站或文档站的框架（`site-frameworks`）。不含组件库与设计系统（见 `web-ui/component-libraries`），不含浏览器自动化（见 `web-automation`），也不含产出 PDF 而非可运行站点的排版与文档编译器（见 `typesetting`）。
