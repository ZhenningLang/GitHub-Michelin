## 本分类项目

| 项目 | 何时用 | 健康度 | 页面 |
| --- | --- | --- | --- |
| **Cline** | 装在编辑器、终端和桌面端的 coding agent：每次改动和命令都等你批准，每一步都留 checkpoint——模型自带。 | B（5/6） | [→](cline.zh.md) |
| **Roo Code** | 「按角色分模式」VS Code agent 的归档原点（2026-05-15）——研究它怎么把模式建在工具组之上，然后迁到 Cline 或 Kilo Code。 | C（6/6） | [→](roo-code.zh.md) |
| **Continue** | 配置驱动的 agent：一份 `config.yaml` 被编辑器、CLI 和 CI 共用——最终 2.0.0（2026-06-19）后只读，当设计参考有用，当运行时已冻结。 | B（6/6） | [→](continue.zh.md) |
| **Kilo Code** | 一个住在 IDE 里的开源 AI 编码 agent：一个 VS Code（及 JetBrains）扩展，会规划、跨文件改代码、跑命令、在多个专职模式之间切换——自带 key（BYOK）接入 500+ 模型，按供应商原价计费。 | A（5/6） | [→](kilocode.zh.md) |
