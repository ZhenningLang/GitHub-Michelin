## 本分类项目

| 项目 | 何时用 | 健康度 | 页面 |
| --- | --- | --- | --- |
| **Codex** | 当你已经在付 ChatGPT 的钱，想让这份订阅在终端里跑一个带沙箱的“改代码、跑测试、再修”循环时用它——但自定义模型提供方必须实现 Responses API，OpenAI 不收外部 PR，0.x 接口几乎天天在变。 | A（5/6） | [→](codex.zh.md) |
| **Gemini CLI** | 当你想要一个用普通 Google 账号登录、在每日额度内免费用、上下文窗口装得下大仓库的终端 agent 时用它——但它只连 Gemini，没有离线或本地模型这条路。 | A（6/6） | [→](gemini-cli.zh.md) |
| **ZCode** | 要同一个自带编程运行时贯通桌面、网页与 CLI，带依赖调度和内容绑定的项目 Hook 信任时用；无默认系统沙箱，开源版原生桌面控制不可用。 | C（5/6） | [→](zcode.zh.md) |

## 对比矩阵

| 项目 | 是否收录 | 健康度 | 关键取舍 |
|---|---|---|---|
| [Codex](codex.zh.md) | ✅ | A（5/6） | 优先要 OpenAI 第一方循环与默认系统沙箱；自定义提供方须支持 Responses。 |
| [Gemini CLI](gemini-cli.zh.md) | ✅ | A（6/6） | 优先要 Google 登录与每日免费额度；运行时只用 Gemini，沙箱须主动开启。 |
| [ZCode](zcode.zh.md) | ✅ | C（5/6） | 自带桌面／网页／CLI agent 与持久工作流，执行隔离和源码发行合规由你承担。 |
