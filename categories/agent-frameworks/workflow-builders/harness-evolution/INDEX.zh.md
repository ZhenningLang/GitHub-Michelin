# harness-evolution

> 分类节点。演化 agent 的运行框架或外部资源，而非训练模型权重。
> ← 返回 [workflow-builders](../INDEX.zh.md) · 根：[分类路由](../../../../INDEX.zh.md) · English: [INDEX.md](INDEX.md)

## 本分类项目

| 项目 | 何时用 | 健康度 | 页面 |
| --- | --- | --- | --- |
| **Gear** | 固定资源版本做演化，持久化评测并按配置验收；研究模式不含独立留出验证。 | B（4/6） | [→](gear.zh.md) |
| **PenguinHarness** | 固定模型和评测集，给运行框架改动分版本、评分；涨分仍需新任务验证。 | B（6/6） | [→](penguin-harness.zh.md) |
| **Hermit** | 比较外部适配文件的多种演化方法，记录反馈和状态而不改模型权重；效果提升须单独评测。 | C（6/6） | [→](hermit.zh.md) |
| **Harness²** | 要在当前任务上无标准答案地调整固定模型 agent 的整套配置；重复试跑花钱，且只从合成终稿选优，仍可能退步。 | C（5/6） | [→](harness2.zh.md) |

## 对比矩阵

| 选项 | 是否收录 | 健康度 | 一句话取舍 |
| --- | --- | --- | --- |
| [Gear](gear.zh.md) | ✅ | B（4/6） | 运行时约束候选证据与预算；仍需原生目标适配器、可信评分与隔离执行。 |
| [PenguinHarness](penguin-harness.zh.md) | ✅ | B（6/6） | 固定模型和评测集，给运行框架改动分版本、评分；涨分仍需新任务验证。 |
| [Hermit](hermit.zh.md) | ✅ | C（6/6） | 统一适配层训练生命周期与宿主导出；结构检查不是效果门控，沙箱能力受平台限制。 |
| [Harness²](harness2.zh.md) | ✅ | C（5/6） | 在任务中递归改配置，并积累领域经验；基线不参与选优，执行器隔离由你负责。 |

## 什么该放这里

演化 agent 的运行框架或外部资源，而非训练模型权重。单一技能文档优化与通用提示词编译保留在父分类。
